
# SciFaersLab 产品说明
> 基于 FAERS 等多个药物不良反应数据库的图形化、零代码药物警戒研究平台。

SciFaersLab 面向医学、药学及生命科学研究人员，
无需编程基础即可完成 FAERS 数据整理、信号检测、亚组分析、
统计分析及论文级图表制作。
> - 整合包解压即用，无需配置R、Sass、Python、SQL等复杂环境

## ✨ 核心能力

### 📊 数据分析

- **[FAERS 数据挖掘](https://www.bilibili.com/video/BV1AHeozNEXt/)**：支持药物不良事件信号检测、基线数据统计及多维度数据分析
- **[亚组分析](https://www.bilibili.com/video/BV1taJdzqEYT/)**：支持年龄、性别、联合用药及特定人群等多种条件下的精细化分析
- **[逻辑回归统计分析](./特殊图像绘制教程/多元Logistic回归分析，单药or多药or联合用药适用.md)**：支持多因素 Logistic 回归等常用统计方法，适用于单药、联合用药及多种研究设计
- **[机器学习分析](https://www.bilibili.com/video/BV1su39zKEPX/)**：支持特征工程及机器学习建模，用于潜在不良反应预测，并可与传统信号检测方法进行性能比较

### 🎨 论文绘图

- **150+ 绘图脚本**：持续更新，覆盖 FAERS 研究中绝大多数常见图表需求
- **论文级图表输出**：支持 PNG、PDF、TIFF、EPS、SVG 等多种格式，满足论文投稿及后续编辑需求
- **图形化操作**：无需编程基础即可完成常见科研图表制作，降低数据分析与绘图的使用门槛
- **英文 / 中文图表**：脚本默认生成英文图表，并支持[一键转换](./特殊图像绘制教程/汉化英文脚本的方法.md)为中文版本
- [查看绘图工具包视频教程](https://www.bilibili.com/video/BV1gBhCzNEpc/)

### 🧬 拓展分析

- **多数据库药物警戒**：支持 [JADER](./旧物/Jader数据库挖掘工具.md)、[CVADR](./旧物/CVARD加拿大数据库挖掘工具.md) 等数据库的数据挖掘与亚组分析
- **[药物相互作用（DDI）](./旧物/DDI药物相互作用计算说明文档.md)**：提供药物联用及相互作用分析工具，辅助开展联合用药安全性研究
- **[网络药理学拓展](./旧物/网络药理学拓展模块.md)**：将 FAERS 数据挖掘与网络药理学分析相结合，支持成分–靶点–通路网络构建与可视化
- **[敏感性分析](./文章套路.md)**：支持药物联用、不同分析条件及研究方案下的敏感性分析，检验研究结果的稳健性

### 📚 研究辅助

- **FAERS 研究模式解析**：总结常见研究设计与分析流程，提供 [八大文章模式解析](./文章套路.md)，辅助快速构建研究方案
- **选题与文献参考**：提供药物历史发表情况、FAERS 相关文章等研究信息，辅助研究方向筛选
- **完整研究流程支持**：从数据提取、统计分析、信号检测到论文绘图，为 FAERS 研究提供一体化工具支持
- **持续更新**：绘图脚本、分析功能及研究资料持续更新，随版本迭代不断扩展研究能力

## 入门建议
选择一篇目标文章，从分析方法、流程设计到图像制作，先评估可行性，然后借鉴其研究思路应用到自己的课题中。接着融合第二篇、第三篇文章的优秀元素，先完成初稿，再逐步精简优化。

### 高效发文策略
1. **选题优势**：此类文章写作难度较低，套路相对固定，方法具有很强的复用性
2. **并行操作**：建议同时开展三个或以上课题的写作工作
3. **选题工具**：附赠的《所有药物发表情况》和《发表文章一览》两个Excel表格（每月更新）可帮助快速筛选研究方向
4. **经济效益**：从投入产出角度考虑，在前期边际成本较低的阶段，文章数量越多，整体收益越高

## 声明与服务说明
### 数据与研究声明
- SciFaersLab 主要用于药物警戒研究、数据探索及科研分析。

- FAERS 属于自发报告数据库，分析结果用于信号发现和假设生成，不能直接用于计算药物不良反应发生率，也不能单独证明药物与不良事件之间存在因果关系。

- 研究结果应结合研究设计、临床背景及其他数据来源进行综合判断。

### 服务说明
- 本平台为自助式服务，主要提供软件使用指导和故障排查
- 论文撰写指导：可推荐在该研究领域发表过三篇以上学术论文的资深硕士/博士
- 付费服务仅限**服务期内**的软件使用和更新
