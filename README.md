## 它解决什么问题

- **数据准备**：内置整理后的季度数据库，省去下载，信号检测工具内自动完成清洗、合并和去重步骤。
- **信号分析**：完成基线统计、信号检测、亚组分析、逻辑回归和机器学习分析。
- **论文绘图**：用图形化绘图工具输出可直接用于论文的图表和统计表。
- **智能答疑**：内置 SciFaersLab 聊天助手，可咨询数据库范围、分析方法和软件操作；AI 回答由大模型生成，使用时请结合原始数据与文献进行甄别。
- **持续更新**：数据库、分析模块和绘图脚本随版本更新，通过邮箱发送整合包。

## 常见问题

**没有编程基础可以使用吗？**  
可以。数据和图表均通过图形界面完成，不需要写代码。

**免费版和完整版有什么区别？**  
免费版提供绘图工具、部分脚本和学习资料；完整版包含分析系统、全套脚本、季度数据整合包和持续更新。

**数据库范围和方法部分应该怎么描述？**  
 [数据库范围和方法说明](./数据库范围和方法说明.md)

**数据库多久更新一次？**  
随FDA官方数据版本更新，通过邮箱推送新的整合包。
[日本JADER](./拓展模块/Jader数据库挖掘工具.md)和[加拿大CVARD](./拓展模块/CVARD加拿大数据库挖掘工具.md)随版本更新，也可以直接从对应官网下载，根据教程导入。

**支持 macOS 吗？**  
目前仅支持 Windows 10 / 11。

**购买后提供论文指导吗？**  
服务以软件使用指导和故障排查为主，不提供论文代写。


## 数据说明

本项目用于药物警戒研究、数据探索和科研分析。FAERS 等自发报告数据库
适合发现风险信号和生成研究假设，不能直接计算不良反应发生率，
也不能单独证明药物与不良事件之间存在因果关系。

研究成果应结合研究设计、临床背景和其他数据来源综合判断。
